# ADR 0018: Add the revision leg to the north star's measure

- Status: accepted
- Re-records: prototype ADR 0037 (alee792/hctl)

## Decision

The north star's measure has a third leg. It reads: empty directory to a
working agent inside the author's harness in five minutes; the same folder
runs headless, scheduled, or staged without edits; and a revision applies,
runs, and attributes to its exact configuration without human hands.

## Evidence

The north star permits amendment only against named evidence. Three things
changed since the measure was first written:

1. The vision names the improvement loop as another author of the same
   artifact, coequal with the person, and the product specification carries
   the agent manifest, provenance join keys, and machine-consumable
   validation that serve it.
2. Published research on harness engineering for self-improvement (Weng,
   Jul 2026) independently identifies the properties this contract provides —
   file-represented editable components, bounded editable surfaces,
   attribution of gains to exact configurations, and permission control
   outside the loop — as the missing infrastructure of self-improving agent
   systems.
3. Harness-updating capability has been observed to be roughly flat across
   model sizes, so loop-driven authorship will be exercised by cheap models
   everywhere; well-formedness validation, not drafting skill, becomes the
   binding constraint.

## Consequences

Every slice can be asked which leg of the measure it improves, and a slice
serving only the revision leg is as ordinary as one serving the first five
minutes. The measure binds only outcomes tenon owns: apply, run, and attribute
are tenon contracts, while the loop's evaluation and selection remain outside
per the specification's non-goals. Both consumers of the artifact receive
balanced consideration across the foundational documents — a decision may
favor one when the tradeoff is evaluated and recorded, never by default — and
the direction audit checks that balance.
